# AEGIS team kit - start here

1. Read `AEGIS_Beginner_Quickstart.pdf` before renting.
2. Run the local practice dashboard and tests from `starter/README.md`.
3. Share the four individual task PDFs in `team/`.
4. Read handbook chapters 1-4 and 18-19 together before independent implementation.
5. P2 follows the cloud setup gates; P3 develops training separately; P4 builds against mock contracts.
6. Keep the agreed spending reserve from the reported $5 credit and check actual billing.

The 51-page PDF and editable Word handbook are at the ZIP root.
Editable diagrams are in `assets/`; Markdown documentation is in `docs/`; blank evidence CSVs are in `evaluation/`.
`presentation/` contains a storyboard and speech draft, not a completed PowerPoint deck.

This kit is a plan and development scaffold, not a completed trained AEGIS application.
Read `TEST_STATUS.md` for what was and was not tested.
P1 (MacBook) has protected PPT time. P4 has protected speech time.
