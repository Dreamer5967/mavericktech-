⚠️ The Failure Mode in Smart Traffic
Modern intelligent traffic signals rely on roadside edge perception (YOLO cameras). When rain, glare, or sensor dropout occurs, systems either blind-revert to rigid timers or dangerously substitute "0 vehicles" for missing inputs, starving congested cross-streets.
🛡️ The AEGIS Solution (PS1 + PS3)
Fuses Smart Technologies PS1 (CARLA 0.9.15 + SUMO + YOLOv10n digital twin) and PS3 (Multimodal VQA + Security Firewall). Preserves the explicit distinction between observed counts, bounded estimates, and missing sensors across the control loop.
📊 Strict Uncertainty Data Contract
A dropped camera emits a null count with a bounded uncertainty interval [lower, upper]. The system never injects fake zeros, triggering uncertainty-aware candidate recovery rollouts.
🚑 Emergency Green Corridor (AEGIS-EVC)
Predictive preemption flushes queues ahead of ambulances, delivering zero-stop waves while enforcing mandatory clearance intervals to protect cross-traffic safety.

Slide 02 / 06 · System Architecture
Three Isolated Planes, One Verified Clock Owner
Rigorous Separation of Authority & Privilege Boundaries (Commit 25d3530)
⚙️ Control Plane (CARLA + SUMO)
Synchronous micro-traffic simulation in Town10HD_Opt across 4 signalized junctions (cam_g1=719, cam_g3=23, cam_g4=189, cam_g5=468). Single clock owner advances time at 0.05s steps; sensor callbacks cannot mutate simulation time.
🚦 Safety Phase Guard (Amal)
Strictly validates every signal transition: minimum green (10.0s), maximum green timeout (60.0s), mandatory clearance sequence [NS_YELLOW -> ALL_RED -> Target], and rejection of stale world state revisions. 12/12 test cases verified.
🖥️ Operator & VQA Plane
Web-based Mission Control dashboard for operators. External VQA and query endpoints possess ZERO actuation privileges, ensuring explainability without actuator vulnerability.
🔒 Security Firewall (Amal)
Screens queries against 6 prompt injection patterns (direct override, jailbreak, unauthorized actuation). Enforces Bearer token RBAC (operator vs vqa_reader vs viewer). 100% defense rate on benchmark fixtures.

🔐 Role-Based Access Control (RBAC)
Strict privilege enforcement: only authenticated operator contexts with matching secrets can trigger actuation. VQA reader and viewer roles return PERMISSION_DENIED.
🖼️ Media Header Sanitization
5MB payload cap and binary magic number verification for PNG (\x89PNG) and JPEG (\xff\xd8\xff). Rejects script injection, executable payloads, and corrupted files.
